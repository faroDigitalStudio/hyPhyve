# HyPhyve

**More Than Mushrooms.**

HyPhyve is the mycology education initiative within the wider Hyphal ecosystem. The website introduces the science of fungi and connects schools, organizations, and curious communities with educational presentations and hands-on workshops.

**Website:** [hyphyve.com](https://hyphyve.com/)

## Features

- Responsive single-page website with original HyPhyve branding, mycology imagery, and two extremely subtle oversized handmark textures
- Educational content covering fungal biology, cultivation, ecology, and emerging applications
- Dedicated presentations and workshops section for classrooms, organizations, and community events
- On-site inquiry form with Formspark submission handling, spam honeypot, and inline confirmation and error states
- Direct contact fallback, social links, and discovery links to Hyphal Health, Hyphal Farms, and The Hyphal Knot
- Search and social metadata, organization schema, and Google Analytics 4 tracking

## Built With

- HTML, CSS, and JavaScript
- Bootstrap 5, adapted from the BootstrapMade Mentor template
- Formspark for educational inquiries (`https://submit-form.com/FXtnH3Fer`)
- Bootstrap Icons and AOS animations

The site is designed for lightweight static hosting, including GitHub Pages. Its current focus is presentations and workshops; educational products can be offered through the broader Hyphal ecosystem without introducing a separate storefront here.

## Assets & Setup

- Place `logo.png`, `favicon.png`, and `hyphyve-apple-touch.png` in `assets/img/`.
- Place `hero.png`, `classroom.png`, and `ecology.png` in `assets/img/`.
- Retain the Mentor vendor files and the `assets/css/main.css` and `assets/js/main.js` paths used by `index.html`.
- Configure Formspark notifications for the intended recipient in the Formspark dashboard and verify a live test submission after deployment. The website itself does not determine the notification inbox.

Images used for educational illustration are not documentation of past events.
